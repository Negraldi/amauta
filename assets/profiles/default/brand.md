# Brand

Neutral. No logo, no organization palette, no templates.

- Text: dark gray on white; one accent color for emphasis; meet WCAG AA contrast.
- Charts: one color per series, a gray for context; never color alone to carry meaning.
- Fonts: the target format's defaults.

An organization profile replaces this file with its approved palette, fonts, logo file names and template names. Logo
and template files stay in the profile's `assets/` folder on this machine.
