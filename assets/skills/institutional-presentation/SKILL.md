## Activation Contract

Load this skill to create or edit an editable PPTX for an institutional audience. Audience, decision, evidence and the
delivery check follow `executive-editorial`; the file mechanics follow `doc-formats`.

## Hard Rules

- Use the template and brand of the project's selected profile. When the project has none, ask for the authorized
  template and its intended use; a neutral draft may proceed meanwhile and says that the brand is pending.
- Never infer a right to use an organization's logo, template or media from an example or from another project.
- Keep the editable source; never overwrite a user's deck: write a new file.
- Test decks hold synthetic data that identifies itself on the slide; never real rows, personal data or credentials.
- Sharing outside the team or publishing needs its own authorization.

## Production and review

1. State the audience and decision; outline one supported conclusion per slide, with source, period, population and
   denominator beside each quantitative claim or in a note.
2. Inspect a provided template before using it: masters, layouts, embedded media, fonts.
3. Look at an early slide and the final representative slides as rendered (export to PDF or images when no
   application can be opened; opening one needs permission). Minimum check: 1366 x 768.
4. Check text overflow, line breaks, contrast, alignment, units, sources and logo placement.
5. Keep the deck marked as a draft while the source, the denominator, the asset permission or the rendered check is
   unverified, and record which checks ran.
