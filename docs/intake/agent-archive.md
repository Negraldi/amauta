Source: the user's private agent archive (`agent.zip`, shared on 2026-11-09 with permission to learn from it; its
content never enters this repository). It holds three rules files and six skills for one person's analytics work in
one organization: about two thirds is private (servers, schemas, a palette, people, business rules, catalogs). The
behavior below was read and rewritten clean-room; no text, code or example was copied. File names are given by role,
not by their private names. Hashes are of the original files.
