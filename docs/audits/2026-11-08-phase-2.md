## Deviations recorded

- ADR 0006 amended: the Stop check runs inside the one Stop hook, which keeps its 60 s timeout; project checkers share
  a 40 s budget and only errors in changed files are reported.
- The communicator's folder boundary is an instruction plus the review pack's list of paths changed outside the
  deliverables folder: Claude Code hooks do not say which subagent made a tool call, so a hook cannot enforce it.
- Codex gets the prompt check and the Stop check, not the Read and edit checks: it reads and edits through its shell.

## Private content search

`git grep` over every tracked file except vendored upstream code: no word from the private archive's names,
organization, product or team (checked with word boundaries), no IPv4 address other than loopback, no e-mail address
other than placeholders. The intake record for the clean-room tools lists hashes only and says what was removed without
naming it. A smoke run of `amauta profile import` on the real archive used a scratch state directory outside the
repository, removed afterwards.
