## Fixes found on the way (all with a test)

- Since N7 the Harness page listed every amauta hook as "other" (the API did not know the dispatcher).
- The graphify git hook, the semantic pass and `amauta portal` called a bare `python3`, which on macOS is Xcode's 3.9
  (no `-P`); they now use the interpreter install recorded (N9b).
- Portal: the pressed state of the memory-source and usage-kind switches never showed (`aria-pressed=""`); the search
  rows lost their spacing in N12c; "1 messages" in the recent feed; raw backticks in server notes.

## macOS

The first macOS run had 22 Node failures (the Python suite never got to run). All are fixed and the macOS job now
blocks. Product fixes: the bare `python3` above; the portal bound through `socket.getfqdn()`, a reverse DNS lookup
that stalled its start; the project path guard let `/etc` through because it resolves to `/private/etc`. Test fixes:
temporary paths compared as `/var` against `/private/var`, an explicit 3.11+ interpreter where a test narrows `PATH`,
and three fakes that used a script as a `#!` interpreter, which macOS refuses (skipped there with that reason; a real
graphify launcher names a binary Python).
